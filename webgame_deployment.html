CONCEPT

컴퓨터 · GitHub · 웹사이트는 다르다

  • • 내 컴퓨터: 파일을 만들고 고치는 곳
  • • GitHub 저장소: 파일과 변경 기록을 보관하는 곳
  • • GitHub Pages: 파일을 웹페이지로 보여 주는 기능
  • • 수정 후에는 다시 Commit과 Push가 필요함

CORE THEORY

왜 이름이 index.html일까?

  • • 웹서버는 폴더 주소로 접속하면 시작 파일을 찾는다.
  • • GitHub Pages는 맨 위에서 index.html 같은 진입 파일을 찾는다.
  • • 그래서 index.html이 우리 게임 사이트의 첫 화면이 된다.
  • • 다른 이름이면 주소 끝에 파일명까지 직접 적어야 한다.
시각 자료 위치: 오른쪽 · 요청-응답 도표
/my-game-arcade/
↓ 시작 파일 찾기
🏠
index.html
게임 선택 메인 페이지
space-game.html
jump-game.html

MAIN PRACTICE 01

게임 허브의 파일 구조

  • • 저장소의 맨 위에 index.html을 새로 만든다.
  • • 게임 HTML 2개 이상을 같은 폴더에 둔다.
  • • 파일명과 링크의 글자가 정확히 같아야 한다.
  • • 처음에는 단순한 구조로 성공한 뒤 폴더를 나눈다.
시각 자료 위치: 오른쪽 · 저장소 폴더 트리
📁 my-game-arcade
├── 🏠 index.html ← 첫 화면
├── 🚀 space-game.html
└── 🏃 jump-game.html
✅세 파일이 같은 높이에 있으면 ./파일명으로 연결 가능!

MAIN PRACTICE 02

클릭해서 이동하는 <a> 태그

  • • a는 anchor, 즉 페이지를 연결하는 태그다.
  • • href에는 이동할 파일 경로를 넣는다.
  • • 태그 사이 글자는 화면에서 클릭할 부분이다.
  • • 같은 폴더의 파일은 상대경로 ./파일명으로 연결한다.
시각 자료 위치: 아래 · 코드 해부도
index.html
<a href="./space-game.html">🚀 우주선 게임 시작</a>

MAIN PRACTICE 03

index.html 만들기

  • • 새 텍스트 파일을 만들고 이름을 정확히 index.html로 저장한다.
  • • 제목과 안내 문장을 작성한다.
  • • 게임마다 <a> 태그를 하나씩 만든다.
  • • target="_blank"로 새 탭에서 열 수 있다.
  • • 브라우저에서 index.html을 열어 두 링크를 시험한다.
시각 자료 위치: 오른쪽 · 완성 코드
index.html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>나의 게임 놀이터</title>
</head>
<body>
  <h1>🎮 나의 게임 놀이터</h1>
  <p>플레이할 게임을 골라 보세요!</p>

  <a href="./space-game.html">🚀 우주선 게임</a>
  <a href="./jump-game.html">🏃 점프 게임</a>
</body>
</html>

LEVEL UP

링크를 게임 버튼처럼 꾸미기

  • • 먼저 링크 이동이 되는지 확인한 뒤 CSS를 추가한다.
  • • display: inline-block으로 버튼 영역을 만든다.
  • • padding, background, color로 모양을 꾸민다.
  • • 두 게임 링크에 같은 class를 사용한다.
<a class="game-button" href="./space-game.html">…</a>

LEVEL UP

  • • 링크 경로에 폴더 이름을 포함한다.
  • • 파일을 옮긴 뒤 모든 링크를 다시 시험한다.

DEBUG

안 열릴 때는 여기부터!

  • • 404: 파일명과 경로의 철자를 비교한다.
  • • 첫 화면 없음: index.html 위치를 확인한다.
  • • 예전 화면: Push 여부와 배포 상태를 확인한다.
  • • 게임만 오류: 개발자 도구 Console을 확인한다.
  • • 링크 오류: C:\...가 아닌 상대경로를 쓴다.
