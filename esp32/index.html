02 · EXPLORE

작은 보드, 현실과 연결되는 컴퓨터

7분

ESP32는 프로그램을 저장하고 실행하는 마이크로컨트롤러입니다. 센서로 주변을 읽고, LED나 모터로 결과를 표현할 수 있어요. 오늘은 출력부터 경험합니다.

입력버튼 · 빛 센서다음 프로젝트에서 만나요
→
처리ESP32 + 프로그램정해진 순서대로 명령 실행
→
출력LED의 빛오늘 직접 제어할 부분

오늘 사용할 세 가지 연결

USB
컴퓨터에서 프로그램을 보내고 보드에 전원을 공급해요.
GPIO 23
코드에서 켜고 끄는 출력 핀입니다. 보드에 적힌 23 또는 IO23을 찾으세요.
GND
회로의 기준점입니다. LED에서 보드로 돌아오는 길을 만들어요.

ESP32-WROOM-32 계열 기준입니다. 핀의 위치는 보드마다 달라요. ‘위에서 몇 번째’ 대신 인쇄된 이름으로 확인하세요. C3·S3 보드에는 그대로 적용하지 않습니다.

준비물 체크

짝과 함께 하나씩 확인하세요.

보드를 브레드보드 밖에 두면 암–수 점퍼선이 편리합니다. 핀 헤더가 장착된 보드를 사용하세요.

03 · CONNECT

전기가 지나는 길을 만들어요

10분
먼저 USB를 분리하세요. 연결을 바꿀 때는 전원을 끕니다. 저항을 반드시 직렬로 연결하고, GPIO에 5V를 연결하지 마세요. 뜨겁거나 냄새가 나면 USB를 즉시 분리하고 선생님에게 알리세요.

브레드보드 연결 지도

전원 레일을 쓰지 않는 간단한 회로

↔ 작은 화면에서는 연결 지도를 좌우로 밀어 보세요.

GPIO 23 → a5저항: e5 ↔ e9LED: 긴 다리 d9 / 짧은 다리 d12 a12 → GND
  1. 번호가 같은 다섯 구멍을 찾기

    이 그림에서는 세로의 a–e가 한 묶음입니다. 실제 보드를 돌려 놓으면 방향도 바뀝니다. 번호와 묶음을 기준으로 보세요.

  2. 저항으로 5번과 9번 묶음 잇기

    저항에는 방향이 없습니다. 330 Ω으로 LED에 흐르는 전류를 제한해요.

  3. LED 방향 확인하기

    긴 다리(+, 애노드)는 d9, 짧은 다리(−, 캐소드)는 d12에 꽂아요. 두 다리를 같은 번호 묶음에 꽂지 마세요. 다리를 자른 LED는 몸체의 평평한 쪽이 보통 −입니다.

  4. 짝과 경로를 따라가고 USB 연결

    그림에서 선이 교차하는 곳은 연결점이 아닙니다. 점퍼선 끝을 지정된 구멍에만 꽂으세요. 23 → 저항 → LED + → LED − → GND. 한 사람은 설명하고 다른 사람은 실제 연결을 확인하세요.

연결 전, 생각해 보기

LED의 두 다리를 같은 번호의 a–e 묶음에 꽂으면 어떻게 될까요?

막혔을 때 힌트

LED의 양쪽이 서로 다른 전기적 지점에 연결되어야 합니다. 브레드보드 안의 금속 연결을 떠올려 보세요. 긴 전원 레일은 중간이 끊어진 제품도 있어 오늘은 사용하지 않아요.

04 · MAKE IT BLINK

켜고, 기다리고, 끄고, 기다리고.

10분

먼저 코드를 읽고 예측하세요. 1000 ms = 1초. 아래는 LED가 켜지고 꺼지는 시간을 살펴보는 화면 속 동작 모형입니다. 실제 보드는 Arduino IDE에서 업로드해야 움직입니다.

blink.ino ARDUINO / C++
setup() 시작할 때 한 번loop() 계속 반복
BLINK PLAYGROUND

실험 준비

두 슬라이더는 코드에도 반영돼요.
주기: 2.0초 · 밝기를 바꾸는 실험은 아니에요.

Arduino IDE에서 실제 보드에 업로드하기
  1. Arduino IDE를 설치합니다. 환경설정의 ‘추가 보드 매니저 URL’에 아래 주소를 넣습니다.https://espressif.github.io/arduino-esp32/package_esp32_index.json
  2. 보드 매니저에서 esp32 by Espressif Systems를 설치합니다. (수업 전 선생님과 준비)
  3. USB를 연결하고 보드를 선택합니다. 일반 WROOM-32 개발보드는 ESP32 Dev Module을 사용하되, 선생님이 확인한 보드 이름을 우선합니다.
  4. 보드가 연결된 포트(COM)를 선택합니다. 포트를 모르겠다면 USB를 뺐다가 다시 연결했을 때 생기는 포트를 확인하세요.
  5. 새 스케치에 전체 코드를 붙여 넣고 검증(✓) → 업로드(→)를 누릅니다. 업로드 완료 후 실제 LED를 관찰하세요.

오늘은 회로와 코드 실험에 집중할 수 있도록 IDE와 보드 패키지 설치를 수업 전에 마칩니다.

LED가 안 켜져요

USB를 분리한 뒤 GPIO 23과 GND, LED 극성, 저항, 브레드보드 묶음을 차례로 확인하세요. 보드의 전원 LED가 켜지는 것과 외부 LED가 동작하는 것은 다릅니다. 짝에게 전류 경로를 설명하고 다시 확인받으세요.

업로드가 안 돼요

충전 전용이 아닌 데이터 케이블인지, 보드와 포트가 맞는지 확인합니다. 연결 대기에서 멈추면 선생님과 함께 업로드 시작 시 BOOT 버튼을 누르고 전송이 시작되면 놓아 봅니다. 포트 자체가 없으면 보드의 USB 변환 칩에 맞는 드라이버를 선생님이 확인합니다.

05 · THINK WITH AI

AI는 제안하고, 우리는 검증해요.

8분

우리 동아리의 상태 하나를 선택하세요. 짝과 먼저 신호를 예상한 뒤, AI에게 시간 값 한 가지를 바꾸는 방법을 물어봅니다. AI가 제안한 핀 번호·시간·회로 조건은 직접 확인해야 해요.

어떤 상태를 알릴까요?

기본 도전: 시간 값 1개 바꾸기
추가 도전: 두 번 깜박이고 쉬는 신호를 순서도로 설명하기

AI에게 건넬 질문

학교에서 허용한 AI 도구와 계정을 사용하세요. 이름·학번·친구 사진·비밀번호는 넣지 않아요. 이 페이지는 AI에 자동으로 연결하지 않습니다.

01. 비교하기

AI 코드의 핀이 23인가요? LED 회로는 그대로인가요?

02. 실행하기

시간 값 한 가지만 바꾸고 검증·업로드해 관찰해요.

03. 설명하기

예상과 달랐다면 원인을 찾고, 짝의 의견으로 수정해요.

AI 접속이 어려우면: 위 깜박임 실험에서 시간 값 하나를 선택하고, 짝이 ‘제안자’가 되어 같은 검증 과정을 진행합니다.

06 · REFLECT & SHARE

불빛보다 중요한 건, 내가 알아낸 것.

5분

성공 여부만 기록하지 않아요. 바꾼 이유와 관찰한 증거를 남기고, 짝의 피드백으로 한 번 더 개선하세요.

처음부터 함께 보는 성공 기준

□ 저항·극성·GND를 확인하며 회로 경로를 설명할 수 있다.

□ 바꾼 시간 값과 실제 LED 동작의 관계를 증거로 설명한다.

□ AI 제안을 확인하고, 짝의 피드백을 반영한 수정 이유를 말한다.

이 브라우저에만 자동 저장 · 제출되지 않아요

공용 PC에서는 기록을 내려받은 뒤 ‘내 기록 지우기’를 누르세요. 이름이나 학번 없이 작성할 수 있습니다.

선생님을 위한 수업 운영 · 교육과정 정합성

45분 운영: 미션 5분 → 개념·준비 7분 → 회로 10분 → 코드 10분 → AI 수정 8분 → 성찰 5분. 설치는 사전에 완료하고 교사용 보드로 GPIO 23과 LED 회로를 시험합니다.

짝 활동: 회로 연결자와 설명·점검자로 시작해 코드 수정 단계에서 역할을 바꿉니다. 둘 다 신호의 의미와 수정 이유를 설명하게 합니다. 중간 피드백은 ‘예상은? → 관찰 증거는? → 다음에 바꿀 한 가지는?’으로 이어갑니다.

맞춤 지원: 어려운 학생은 연결 지도와 기본 코드, 시간 값 1개 수정으로 시작합니다. 빠른 학생은 반복 신호의 순서를 설계하고 다른 사람이 같은 의미로 이해하는지 검증합니다.

교육과정 연결(설계 해석): 중학교 정보의 컴퓨팅 시스템·피지컬 컴퓨팅 및 알고리즘·프로그래밍 학습과 연결한 동아리 입문 활동입니다. 학년 혼합 동아리이므로 특정 학년의 성취기준을 이 한 차시에서 모두 달성했다고 판단하지 않습니다. 담당 교사는 소속 학년의 적용 교육과정과 학교 교육계획에 맞춰 평가에 활용합니다.

대구미래역량교육과정 정합성: 신호의 의미를 스스로 선택하는 자율성, 예측–실험–수정의 주도성, 짝과 설명·상호 피드백하는 관계성을 반영했습니다. 창의융합적 사고는 코드와 동작의 관계 설명, 공감·소통은 신호 해석과 짝 피드백, 자기관리는 안전 점검과 실험 기록, 공동체 역량은 책임 있는 AI 활용과 모두가 이해할 신호 설계로 관찰합니다. 결과물뿐 아니라 탐구·협력·수정 과정을 성공 기준으로 확인합니다.

정합성 점검: 목표(출력 관계 설명·안전한 연결·AI 검증) ↔ 활동(연결·시간 변경·상호 점검) ↔ 증거(실제 LED 관찰·탐구 기록·수정 설명)가 일치하도록 구성했습니다.
