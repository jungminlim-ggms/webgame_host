02 · READ THE INPUT

누르면 0? 입력의 약속을 알아봐요.

8분

이번 회로는 INPUT_PULLUP을 사용합니다. 보드 안의 저항이 버튼을 놓았을 때 입력을 HIGH(1)로 유지하고, 버튼을 누르면 GND와 연결되어 LOW(0)가 됩니다. ‘눌림 = 1’이라는 규칙이 항상 맞는 것은 아니에요.

03 · CONNECT & RUN

LED 회로에 버튼 입력을 더해요.

10분
USB를 분리하고 연결하세요. 1차시의 330 Ω 저항과 LED 극성을 유지합니다. 버튼은 GPIO 18과 GND 사이에 연결하고, 5V에 연결하지 않습니다. 뜨겁거나 냄새가 나면 전원을 분리하고 선생님에게 알리세요.

브레드보드 연결 지도 · LED + 버튼

1차시 LED 연결 유지 · 버튼 회로만 추가

↔ 작은 화면에서는 연결 지도를 좌우로 밀어 보세요.

GPIO 23 → a5저항 e5 ↔ e9LED + d9 / − d12 GND → a12 GPIO 18 → a16 추가 점퍼 b12 ↔ b18

선이 교차하거나 구멍 위를 지나가는 곳은 연결점이 아닙니다. 색 점으로 표시한 선 끝만 지정된 구멍에 꽂으세요. ESP32 그림은 핀 이름을 설명하는 개념도이며 실제 보드의 핀 위치는 다를 수 있습니다.

  1. 1차시 LED 회로 유지하기

    저항 e5–e9, LED 긴 다리 d9·짧은 다리 d12, GPIO 23 → a5, GND → a12를 확인합니다.

  2. 버튼 접점을 확인하고 홈을 가로질러 꽂기

    그림은 A1=e16, A2=f16 / B1=e18, B2=f18에 놓는 예입니다. e16–f16이 항상 연결되고 e18–f18도 항상 연결되는 접점 배치인지 전원을 빼고 먼저 확인하세요. 제품의 핀 간격이나 내부 연결이 다르면 구멍 위치를 그대로 따라 하지 말고, 선생님과 A·B가 분리되는 배치로 조정합니다.

  3. 버튼 입력과 공통 GND 연결하기

    GPIO 18 → a16을 연결합니다. b12 → b18 점퍼선으로 LED 쪽 GND를 버튼의 B 접점까지 이어 줍니다. a12·b12·d12는 같은 묶음이고, b18·e18도 같은 묶음입니다.

  4. 짝과 누름·놓음 경로를 설명하기

    놓으면 A–B가 분리되어 INPUT_PULLUP으로 HIGH. 누르면 GPIO 18 → A → B → GND 경로가 이어져 LOW. 연결을 확인한 다음 USB를 연결합니다.

준비물 · 연결 체크

LED: GPIO 23 → 330 Ω → LED + / LED − → GND

버튼: GPIO 18 → 버튼의 한 접점 / 다른 접점 → GND

LED와 버튼 모두 같은 ESP32의 GND를 사용합니다. INPUT_PULLUP을 쓰므로 이 버튼 회로에는 별도 풀업 저항이 필요하지 않습니다. LED의 330 Ω 저항은 계속 필요합니다.

A·B는 설명을 위한 이름입니다. 다리의 겉모양만 보고 판단하지 마세요. 선생님과 제품 도면 또는 전원을 뺀 상태의 도통 측정으로 항상 연결된 두 다리씩을 찾습니다. A와 B가 브레드보드의 같은 연결 묶음에 들어가지 않게 꽂으세요. 홈을 가로지르는 방향도 실제 접점 배치에 맞춰 확인합니다.

AI 없이 진행하거나 도움이 필요할 때

현재 코드의 조건 buttonState == LOW를 HIGH로 바꾸면 언제 켜질지 먼저 예측합니다. 업로드해 비교한 뒤 도움 요청이라는 목적에 맞는 조건을 선택하세요. 한 명이 제안하고 다른 한 명이 근거를 확인합니다.

‘한 번 누르면 켜지고 다시 누르면 꺼짐’은 다음 차시 도전입니다. 상태 기억, 눌림 순간 감지, 버튼 튐 처리가 함께 필요하므로 조건문만 뒤집어 구현하지 않아요.

교사용 운영 안내 · 교육과정 정합성 점검

45분 운영: 복습·미션 5분 → 입력 예측·모형 8분 → 회로·코드 실행 10분 → AI와 신호 설계 12분 → 짝 검증 5분 → 성찰 5분. 교사는 사전에 버튼 접점, GPIO 18, 1차시 LED 회로, 보드 업로드를 확인합니다. 연결에 시간이 더 필요하면 깜박임 변형을 생략하고 기본 코드와 의미 전달 검증에 집중합니다.

학습 연결: 정보 교과의 컴퓨팅 시스템과 프로그래밍 학습에 연결하는 동아리 활동입니다. 특정 학년 성취기준의 달성을 이 한 차시만으로 판정하지 않습니다. 핵심 개념은 입력·조건·출력이며 핵심 아이디어는 ‘시스템은 입력 상태를 읽고 조건에 따라 다른 출력을 만든다’입니다.

과정 피드백: ‘무엇을 예상했니? → 입력값은 실제로 무엇이었니? → 어느 조건이 실행됐니? → 다음에 무엇을 바꿀까?’로 질문합니다. 어려운 학생에게 핀 연결과 기본 코드 발판을 제공하고, 빠른 학생은 응답 신호 순서도를 설계합니다.

평가: 공통 성공 기준인 입력–조건–출력 설명, 예측·관찰 비교, AI 검증·짝 피드백에 따른 수정 이유를 관찰과 탐구 기록으로 확인합니다. 실패한 회로라도 오류를 찾고 수정한 과정에 피드백합니다.

대구미래역량교육과정 정합성: 신호의 목적과 표현을 선택하는 자율성, 예측–실험–수정의 주도성, 역할 교대와 공동 검증의 관계성을 반영합니다. 창의융합적 사고는 입력과 출력의 인과 설명, 공감·소통은 신호 해석 비교, 자기관리는 안전·검증 기록, 공동체 역량은 다른 사람도 이해하고 이용할 신호 설계로 드러납니다. 목표–활동–평가를 동일한 수행과 증거로 연결했습니다.
