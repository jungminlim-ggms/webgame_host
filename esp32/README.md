# ESP32 LAB · 1차시

중학생 프로그래밍 동아리 / ESP32-WROOM-32 계열 / 45분.

GitHub Pages: https://jungminlim-ggms.github.io/webgame_host/esp32/

빌드 없이 `index.html`, `style.css`, `app.js`를 제공하는 정적 웹페이지입니다. 저장소의 main 브랜치 루트 Pages 설정을 이용합니다. 별도 서버나 AI API 키가 필요하지 않습니다. 폰트만 Google Fonts를 사용하며 연결되지 않으면 시스템 폰트로 표시합니다.

## 사전 준비
- Arduino IDE와 Espressif ESP32 보드 패키지 설치, 데이터 USB 케이블 및 포트 확인.
- 핀 헤더가 장착된 보드, 브레드보드, LED, 330 Ω 저항, 점퍼선 준비.
- GPIO 23 → 330 Ω → LED 애노드, LED 캐소드 → GND 회로를 교사가 실제 보드에서 사전 확인.
- 학교에서 허용한 생성형 AI 도구 및 계정 준비. 연결 불가 시 짝 제안 활동으로 대체.

화면 깜박임은 동작 모형이며 실제 회로·코드 컴파일을 시뮬레이션하지 않습니다. 브레드보드 그림은 번호별 a–e 묶음을 기준으로 연결합니다. 보드의 핀 위치 대신 핀 이름을 확인합니다.

탐구 기록은 브라우저 localStorage에만 저장되며 서버 제출 기능은 없습니다. 텍스트 내려받기 후 공용 PC의 기록을 지울 수 있습니다. 하드웨어 실물 검증은 별도로 필요합니다.
